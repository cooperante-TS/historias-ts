Manual de gestión de Historias TS

Esta guía permite mantener el timeline sin conocimientos de programación. El contenido habitual se gestiona desde la hoja institucional; los cambios de diseño o funcionamiento pueden pedirse a ChatGPT/Codex sobre el repositorio institucional.

Publicar un nuevo hito

  1. Abre la hoja institucional de gestión.
  2. Entra en el país correspondiente y crea una fila con un ID único.
  3. Completa fecha, tipo, título, resumen, imagen y fuente.
  4. Trabaja primero como BORRADOR, después REVISAR y finalmente PUBLICAR.
  5. Abre la web y comprueba el resultado antes de dar el hito por cerrado.
Importante: la hoja privada de gestión no debe hacerse pública. El feed técnico puede ser públicamente legible para que funcione la web, pero nunca públicamente editable.

Pedir un cambio a ChatGPT/Codex

Selecciona el repositorio institucional de esta web y utiliza como base:

Lee primero AGENTS.md y la documentación de docs/. Quiero realizar este cambio: [DESCRIBIR CAMBIO]. Mantén el funcionamiento actual, las rutas por país, el modo embed de WordPress, el diseño responsive y la copia segura de datos. Trabaja en una preview o rama de prueba. Antes de publicar, dime exactamente qué has cambiado y qué has comprobado.

Qué debe comprobarse

  • La web abre y muestra contenido.
  • Se puede cambiar entre los seis países.
  • Los botones anterior y siguiente funcionan.
  • Las imágenes que fallen muestran una alternativa legible.
  • El modo WordPress con &embed=1 funciona.
  • Los datos siguen visibles aunque Google Sheets falle temporalmente.

Si algo falla

Primero revisa la última preview o despliegue. Si el problema empezó tras una modificación, restaura la versión anterior desde GitHub/Cloudflare. Si sólo fallan los datos nuevos, revisa el feed y el estado PUBLICAR; si sólo falla una imagen, sustituye la URL por un recurso estable de TS.
